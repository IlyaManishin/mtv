# Compiler — Текстовый редактор для языкового процессора

Графическое приложение (GUI) на **Python** и **PyQt6**, разработанное в рамках лабораторного практикума по теории языковых процессоров. Представляет собой специализированный текстовый редактор с интегрированным двухфазным анализатором условного оператора языка Python (`if-else`).

---

## 🚀 Основные возможности (Фичи)

### 1. Текстовый редактор
- **Многодокументный интерфейс (вкладки):** возможность одновременной работы с несколькими файлами в одном окне, переключение и закрытие вкладок, автоматический контроль несохраненных правок (запрос на сохранение при закрытии вкладки или программы).
- **Нумерация строк:** настраиваемая левая полоса с отображением номеров строк, синхронизированная с прокруткой и размером шрифта.
- **Подсветка синтаксиса:** выделение ключевых слов (`if`, `else`, `and`, `or`), операторов, строковых и числовых литералов, а также комментариев.
- **Динамическое масштабирование (Zoom):** изменение размера шрифта в редакторе и консоли через меню, горячие клавиши (`Ctrl + +`, `Ctrl + -`, `Ctrl + 0`) или колесико мыши (`Ctrl + Wheel`).
- **Drag & Drop:** открытие текстовых файлов путем перетаскивания из файлового менеджера прямо в окно редактора.
- **Интерактивная подсветка текущей строки:** мягкое фоновое выделение строки курсора.

### 2. Двухфазный языковой процессор
- **Токенизатор (Lexer) с поддержкой реальных отступов Python:**
  - Автоматическое отслеживание уровней отступов через стек (`indent_stack = [0]`).
  - Генерация терминалов `INDENT`, `DEDENT` и `NEWLINE` на основе реальных отступов (пробелов/табуляций) и переводов строк `\n`.
  - Каждый токен сохраняет точные координаты: тип, строковое значение, номер строки (1-based), номер столбца (1-based), абсолютное смещение в тексте и длину.
  - Определение ошибок некорректных отступов (`IndentationError`) и нераспознанных символов.
- **Синтаксический анализатор (Parser) с поиском максимума ошибок:**
  - Реализация метода рекурсивного спуска для грамматики условного оператора:
    ```text
    if <Condition>:
        <ident> = <ident>
    else:
        <ident> = <ident>
    ```
  - **Panic-Mode Error Recovery (Режим паники со множествами синхронизации):** парсер не прерывает работу на первой ошибке, а восстанавливается на ключевых синхронизирующих токенах (`:`, `NEWLINE`, `INDENT`, `DEDENT`, `else:`) и находит все синтаксические несоответствия во всем тексте за один проход.
  - **Вставочное восстановление (Follow-set synchronization):** определение пропущенных терминалов (например, забытого двоеточия `:`) без отбрасывания следующих токенов.

### 3. Интерактивная таблица ошибок и навигация
- Табличное отображение всех обнаруженных лексических и синтаксических ошибок: `№`, `Файл`, `Строка`, `Столбец`, `Сообщение`.
- **Навигация в один клик:** щелчок (или двойной щелчок) по строке ошибки в таблице мгновенно переносит курсор текстового редактора к месту ошибки и подсвечивает проблемную строку желтым цветом.

### 4. Интерфейс и удобство
- **Разделитель панелей (QSplitter):** плавное изменение соотношения высоты области редактирования и области вывода результатов.
- **Векторные иконки панели инструментов:** качественные векторные пиктограммы, отрисовываемые программно через `QPainter` (не зависят от системных тем ОС и масштабирования дисплея).
- **Интернационализация (i18n):** мгновенное переключение языка интерфейса между русским и английским через меню «Локализация».
- **Строка состояния:** отображение статуса готовности, текущей строки и столбца курсора.
- **Поддержка Ctrl + C:**
  - В терминале: мгновенное и чистое завершение процесса через обработчик `SIGINT` без зависания Qt-петли.
  - В интерфейсе: корректное копирование текста из активного виджета с фокусом.

```text
mtv/

│       │   ├── editor_tabs.py      # Управление вкладками документов
│       │   ├── error_table.py      # Таблица ошибок компилятора
│       │   └── output_panel.py     # Панель вывода (консоль + таблица ошибок)

│           ├── about_dialog.py     # Окно «О программе»
│           ├── help_dialog.py      # Руководство пользователя

│   └── test_compiler_gui.py   # Модульные и интеграционные тесты
└── requirements.txt           # Зависимости Python
```

## 🛠️ Установка и запуск

### Требования
- Python 3.10+
- PyQt6

### 1. Создание виртуального окружения и установка зависимостей
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
.venv/bin/python -m src.main
```
или, если виртуальное окружение уже активировано:
```bash
python -m src.main
```

### 3. Запуск тестов
```bash
.venv/bin/python -m unittest tests/test_compiler_gui.py
```

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + N` | Создать новый документ во вкладке |
| `Ctrl + O` | Открыть файл с диска |
| `Ctrl + S` | Сохранить текущий документ |
| `Ctrl + Shift + S` | Сохранить документ как... |
| `Ctrl + Q` | Выход из программы |
| `Ctrl + Z` | Отменить последнее действие (Undo) |
| `Ctrl + Y` | Повторить отмененное действие (Redo) |
| `Ctrl + X` | Вырезать фрагмент в буфер обмена |
| `Ctrl + C` | Скопировать фрагмент в буфер обмена |
| `Ctrl + V` | Вставить фрагмент из буфера обмена |
| `Delete` | Удалить выделенный текст |
| `Ctrl + A` | Выделить весь текст документа |
| `Ctrl + +` / `Ctrl + =` | Увеличить размер шрифта (Zoom In) |
| `Ctrl + -` | Уменьшить размер шрифта (Zoom Out) |
| `Ctrl + 0` | Сбросить масштаб к стандартному размеру |
| `Ctrl + Wheel` | Масштабирование колесиком мыши |
| `F5` | Запуск синтаксического анализатора (Пуск) |
| `F1` | Вызов справки — руководства пользователя |
